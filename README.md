# Four/H/ Homestay Booking System

## Project Overview

Welcome to the **Four/H/ Homestay Booking System**, a simple C-based program that allows users to book rooms at a homestay. The program lets customers choose from a variety of room types and apply discounts if eligible. The program then calculates and displays the total bill based on the room selected, number of days, and any applicable discounts.

---

## Features

1. **Room Selection**: Customers can choose from the following room types:
   - Master Bedroom
   - Single Bedroom 1
   - Single Bedroom 2
   - Twin Sharing

2. **Discounts**: Two discount codes are available:
   - **24681**: 10% discount
   - **13579**: 30% discount

3. **Bill Calculation**: The program calculates the total bill based on:
   - Room price per night
   - Number of days
   - Utility bills (fixed at RM 50 per day)

---

## How to Use the Program

1. **Start the Program**: Run the program, and you will be prompted to enter your name.
   
2. **Choose Your Room**: After entering your name, you will be prompted to select a room type by entering the corresponding number:
   - 1 for Master Bedroom
   - 2 for Single Bedroom 1
   - 3 for Single Bedroom 2
   - 4 for Twin Sharing
   
3. **Enter Number of Days**: Specify how many days you want to stay.

4. **Enter Discount Code**: If you have a discount code, enter it. If not, simply enter **0**.

5. **View Payment Receipt**: The program will calculate your total bill and display a detailed payment receipt, including room price, utility bills, discount applied (if any), and the final total.
